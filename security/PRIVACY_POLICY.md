## 2. Quais dados coletamos

### 2.1 Dados que o site NAO coleta

Este site **nao coleta, nao armazena e nao processa** diretamente nenhum dos seguintes dados:

- Nome, e-mail, CPF, telefone ou qualquer dado pessoal via formulario (o site nao tem formularios)
- Cookies de identificacao ou rastreamento
- Dados de navegacao (paginas visitadas, tempo de permanencia, etc.)
- Dados de localizacao
- Dados de dispositivo alem dos enviados pelo proprio navegador no HTTP padrao

### 2.2 Dados processados por terceiros ao usar o site

| Dado | Quem recebe | Por que | Base legal provavel |
|---|---|---|---|
| Endereco IP do visitante | Cloudflare CDN (cdnjs.cloudflare.com) | Entrega da biblioteca Three.js (efeito visual do site) | Legitimo interesse |
| Endereco IP + User-Agent | Google LLC (fonts.googleapis.com) | Entrega das fontes tipograficas Bodoni Moda e Inter | Legitimo interesse |
| Endereco IP do visitante | GitHub Inc. (GitHub Pages) | Hospedagem do site | Execucao de servico |

**O site nao recebe de volta nenhum dado identificavel desses servicos para fins de rastreamento.**

### 2.3 Dados fornecidos voluntariamente via canais de contato

Quando voce entra em contato pelo **WhatsApp** ou **e-mail** listados no site:

- Seus dados (nome, telefone, mensagem) ficam armazenados exclusivamente no **aplicativo WhatsApp** (Meta Platforms) ou no **provedor de e-mail** do remetente e do destinatario (Bruno)
- O site em si nao processa nem armazena esses dados
- A comunicacao por WhatsApp segue as politicas de privacidade da Meta Platforms
- A comunicacao por e-mail segue as politicas do provedor de e-mail usado

## 7. Seguranca

Adotamos as seguintes praticas de seguranca:

- HTTPS obrigatorio no site (certificado automatico GitHub Pages)
- Nenhum dado pessoal armazenado em banco de dados proprio
- Cabecalhos de seguranca HTTP implementados
- Auditoria de dependencias de software (Gitleaks pre-commit)
- Subresource Integrity (SRI) nos scripts externos para prevenir adulteracao
